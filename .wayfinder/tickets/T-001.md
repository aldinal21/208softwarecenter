## Question

Bagaimana konfigurasi compiler MinGW-w64 x86 (i686) dan Makefile/build script yang tepat agar menghasilkan binary portable yang kompatibel 100% dengan Windows XP SP3 (subsystem 5.1) hingga Windows 11 tanpa dependency runtime eksternal?

## Scope & Deliverables
- Verifikasi instalasi MinGW-w64 i686 (32-bit).
- Buat `Makefile` / `build.bat` dengan flag `-static -mwindows -Wl,--subsystem,windows:5.1 -lgdiplus -lcomctl32 -lcomdlg32 -lole32 -luxtheme`.
- Buat `app.manifest` untuk mendukung Windows XP Theme dan Modern Windows Styles (Common Controls v6).
- Buat minimal test entrypoint (`main.cpp` / `resource.rc`) untuk memvalidasi kompilasi dan subsistem 5.1 PE header.
