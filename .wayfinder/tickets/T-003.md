## Question

Bagaimana implementasi window utama Win32 dengan dukungan Universal Drag & Drop (dari File Explorer, Browser, WhatsApp Desktop/Web, maupun File Manager lain via `WM_DROPFILES` + OLE `IDropTarget`) yang instan dan intuitif untuk operator toko 208, beserta sidebar kontrol (jumlah foto & tombol aksi)?

## Scope & Deliverables
- Window layout: Left panel (Controls & Inputs) + Right panel (Interactive Sheet Preview Canvas).
- Handler Drag & Drop ganda (`WM_DROPFILES` dan OLE `IDropTarget`) untuk menerima file JPG, PNG, BMP, JPEG dari berbagai sumber aplikasi.
- Feedback visual saat file di-drag di atas canvas (drop zone highlight).
- Responsif terhadap resolusi layar standar kasir (mulai dari 1024x768 hingga 1080p+).
