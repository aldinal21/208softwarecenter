## Question

Bagaimana implementasi render resolusi tinggi (300 DPI) ke printer Windows lokal via GDI Print Spooler serta fitur export file (JPG/PNG) siap cetak tanpa pecah?

## Scope & Deliverables
- Integrasi Windows Print Dialog (`PrintDlg` / GDI `StartDoc`, `StartPage`, `EndDoc`).
- GDI+ Image Exporter dengan resolusi 300 DPI.
- Opsi rendering garis potong (cut guide) tipis berwarna abu-abu.
