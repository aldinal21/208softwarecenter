## Question

Bagaimana algoritma penataan (packing algorithm) optimal untuk meletakkan kombinasi pas foto (2x3, 3x4, 4x6) pada lembar kertas A4 (210 x 297 mm) yang dirapatkan ke sudut atas (Top-Left Aligned), lengkap dengan margin potong dan garis potong (cut marks)?

## Scope & Deliverables
- Algoritma perhitungan koordinat (X, Y, Width, Height dalam milimeter dan konversi ke pixel 300 DPI / screen DPI).
- Preset paket (misal: Paket Campur, Paket Ijazah) serta input jumlah per ukuran.
- Output struktur data layout untuk dipakai oleh preview canvas dan printing engine.
